# Benchmarking Differential Expression Classification in Single-Cell Perturbation Models

This repository contains code needed to reproduce analysis in the manuscript.

## Overview

There are in total 8 benchmarked methods, each wrapped within its own folder:

| Method | Code | Dependency Requirement | 
| --- | --- | --- | 
| Perturbation Majority Vote | `majority_vote/` | `environment.yml` |
| KNN Classifier | `KNN_vote/` | `environment.yml` |
| Regularized Logistic Regression | `logistic_reg/` | `environment.yml` |
| Scouter | `Scouter/` | `environment.yml` | 
| TranScouter | `TranScouter/` | `environment.yml` |
| Variational Autoencoder | `VAE/` | See VAE Readme |
| scVI | `scVI/` | See scVI Readme |
| STATE | `STATE/` | `environment.yml` |

For post-prediction distributional calibration, code is stored in `calibration/`.

Exploratory data analysis code in `EDA/`.

## Data Processing Pipeline

DE labels and data splits are generated by running the following:

### 1. DE Calling
DE labels are computed per perturbation via Wilcoxon rank-sum test with Benjamini–Hochberg correction. DE threshold is $p < 0.01$ and $|log2FC| >= 0.00$

```
# script at majority_vote/DE_DOC_stats.py
python DE_DOC_stats.py --adata {dataset}_raw.h5ad --output data/DE_DOC_{dataset}.csv
```

Outputs: `data/DE_DOC_{dataset}.csv`

### 2. Train Test Split (80/20)
Perturbations are stratified by dominant DE classes, written as a `split_80` column into the splitted CSV.

```
# script at majority_vote/train_test_split.py
python train_test_split.py   # test_size=0.20, random_state=305
```

Outputs: `data/DE_DOC_{dataset}_splitted.csv` (adds `split_80` column)

### 3. Calibration Split (60/20/20)
25% of training perturbations (from `split_80 == 'train'`) are carved out as a calibration set for hyperparameter tuning. Written as a `split_calib` column; the test set is untouched.

```
# script at majority_vote/calibration_split.py
python calibration_split.py data/DE_DOC_{dataset}_splitted.csv   # cal_size=0.25
```

Outputs: adds `split_calib` column in-place to `data/DE_DOC_{dataset}_splitted.csv`

### NOTE
Although there is a calibration split, it is combined into the test split to form the final 40% test set for final performance reporting.

It was originally set for tuning calibration hyperparameters (ex. sparsity ratio $r$ in sparsity calibration, can see scripts for this in `calibration/tuning/`), but empirical results have found that hyperparameters have negligible effect on calibration performance, so the calibration split was dropped (i.e., ended up using a **60/40 train test split**).
